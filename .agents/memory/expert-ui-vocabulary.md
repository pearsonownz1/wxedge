Use “expert” and “experts” in the CRM’s visible labels and headings, including “Add expert” and “Expert pipeline.” Classification is an expert tier, STANDARD or PREMIUM. Keep underlying investor database and API naming unchanged.

**Why:** The user requested expert terminology and STANDARD/PREMIUM tiers across forms, filters, displays, and CSV validation, without modifying stored records, Kalshi, or other services.

**How to apply:** New visible UI copy should use expert terminology. Do not rename persisted fields, API endpoints, technical CSV headers, or data models merely to match display wording.
